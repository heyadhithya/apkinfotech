# Complete APK Infotech Website Implementation Plan

> Use subagent-driven-development for independent programme/gallery tasks and inline execution for coupled site/enquiry work. The user's master brief authorizes one-shot execution without routine approval gates.

**Goal:** Complete the existing professional site with seven programme pages, accessible discovery/gallery/navigation, truthful enquiries and production SEO.
**Architecture:** Static programme and policy pages share the current catalogue and design. A course-aware client form uses a small validated server endpoint when a verified webhook is configured, otherwise user-reviewed WhatsApp and official registration. Metadata, business data and route schema share a site module. No new product dependencies or services.
**Stack:** Next.js App Router, React, TypeScript, CSS, Node24/native tests.
**Spec:** docs/superpowers/specs/2026-10-09-complete-site.md
